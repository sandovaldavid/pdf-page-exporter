Chrome extension for Google Drive and Docs

Turn the pages you already see into a PDF.

What it handles

A useful PDF, not a screenshot.

The Google viewer draws each page as an image. The extension collects them in order and assembles the PDF with each page's own size and orientation.

Every page keeps its shape

Size and orientation come from the page itself, not from a fixed template. A wide appendix doesn't get squeezed into A4.

Long documents work too

The extension captures pages as it scrolls the viewer, so it doesn't skip pages that load late. Testing included a 194-page document.

You choose the quality

Name the file, choose high, balanced, or compact quality, and cancel from the progress bar if you change your mind.

Your browser does the work

Nothing is uploaded. The PDF is assembled in memory and saved directly to your computer.

How it works

From an open tab to a saved file.

You don't need to download the document or upload it anywhere. The extension works with what the viewer already has on screen.

  1. 01

    Open the document

    Open it in the Google Drive or Docs viewer. The extension only runs on those two domains.

  2. 02

    Export it

    Click the extension icon, choose a name and quality, and let the automatic scroll reach pages that haven't rendered yet.

  3. 03

    Save the PDF

    You can cancel from the progress bar at any time. When the export finishes, the file is in your downloads folder.

Privacy

Your document stays on your device.

The extension reads the page images the viewer already shows and assembles them in memory. There is no server to send them to, and no account to create.

Read the privacy policy
  • The export sends nothing to a server.
  • No analytics, telemetry, or advertising.
  • No account and no cookies from the extension.
  • Page images are discarded when the export ends or when you cancel it.

Known limits

What it does well, and what it does not.

The extension does one thing, and these limits matter before you rely on it.

Drive and Docs viewer only

It depends on the Google viewer's page structure. Other viewers and websites are not supported.

The PDF is made of images

Each page is stored as an image, so you cannot search or select text in the file.

Sharpness follows zoom

What you see is what gets exported. Raise the viewer zoom before exporting if you need more detail.

Long documents take time

In testing, a 194-page document took about 8 minutes. The progress bar updates as pages are captured, so you can tell it is still working.

The extension does not download the original document or bypass permissions. It exports pages your browser can already display. Use it only with documents you have permission to access.

Install

Install it from the repository.

It isn't on the Chrome Web Store yet. Until then, you can load it unpacked in a few minutes.

  1. Clone the repository.

    git clone https://github.com/sandovaldavid/pdf-page-exporter.git

  2. Open chrome://extensions and turn on Developer mode.

  3. Click Load unpacked and select the repository folder.

  4. Open a PDF in the Google Drive or Docs viewer, then click the extension icon.
